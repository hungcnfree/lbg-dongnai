# 🤖 Kỹ Năng Antigravity: Tự Động Điền Lịch Báo Giảng Tuần (2-File Rule)

> **Dành cho giáo viên sử dụng Antigravity AI:** Tự động hoàn thành bảng lịch báo giảng tuần chuẩn CSDL Giáo dục chỉ trong 3 giây.  
> Bản quyền: **© 2026 Cộng Đồng Giáo Viên Chuyển Đổi Số 🌻☀️**.

---

## 🎯 QUY TẮC 2 FILES TỐI GIẢN
Thầy/Cô chỉ cần gửi cho AI đúng **2 file**:
1. **1 File Mẫu Tuần (`.xlsx`)**: Tải từ hệ thống CSDL hoặc file lịch tuần trước của chính thầy/cô.
2. **1 File TKB Toàn Trường (`.csv` hoặc `.xlsx`)**: File thời khóa biểu chung do nhà trường/BGH xuất ra.

---

## 🚀 CÁCH CÀI ĐẶT VÀO ANTIGRAVITY (CHỈ 1 BƯỚC)

1. Sao chép thư mục `tu-dong-dien-lich-bao-giang` này vào thư mục kỹ năng Antigravity của thầy cô:
   ```text
   C:\Users\<Tên_Máy_Tính>\.gemini\config\skills\tu-dong-dien-lich-bao-giang\
   ```
2. Mở Antigravity lên, kỹ năng đã sẵn sàng hoạt động ngay lập tức mà không cần khởi động lại.

---

## 💬 CÁCH SỬ DỤNG HÀNG TUẦN

1. Kéo thả 2 file vào khung chat Antigravity.
2. Nhắn lệnh:
   > *"Điền lịch báo giảng tuần 12 cho tôi"*  
   > *(hoặc: "Tạo lịch báo giảng tuần mới từ 2 file này")*
3. AI sẽ tự động:
   - Nhận diện Họ tên giáo viên.
   - Trích xuất thời khóa biểu của thầy/cô.
   - Tự động tăng lũy kế số tiết PPCT chuẩn xác cho từng môn và từng lớp.
   - Xuất file Excel `LichBaoGiang_Tuan[X]_[TenGV].xlsx` hoàn tất 100%!
