HƯỚNG DẪN CÀI ĐẶT (3 BƯỚC — CHƯA ĐẾN 1 PHÚT)

Cài 1 lần dùng mãi
1

Giải nén & Chạy File .bat

Tải file ZIP về, giải nén và nhấp đúp chạy file CAI_DAT_TIEN_ICH_CHROME.bat. File sẽ tự sao chép đường dẫn và mở sẵn trang quản lý tiện ích Chrome.

2

Nạp Tiện Ích Vào Chrome

Trên trang Chrome vừa mở, bật công tắc "Chế độ dành cho nhà phát triển" (góc trên bên phải) ➔ Bấm "Tải tiện ích đã giải nén" ➔ Chọn thư mục chrome_extension.

3

Lưu Cấu Hình Của Thầy/Cô

Bấm vào biểu tượng 🧩 Trợ Lý CSDL ở góc trên Chrome. Chọn Tên hoặc Trường của mình, điền Số điện thoại & Mật khẩu rồi bấm 💾 Lưu Cấu Hình là xong!
